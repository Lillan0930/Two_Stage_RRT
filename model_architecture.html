Two-stage Modality-aware R²T + ABMIL （"染色即区域" MSA 版）

C16 配置：HE + PR · input_dim=768 · mlp_dim=512 · region_num=4 · n_layers=2 · n_heads=4 · epeg_k=9 · crmsa_k=3 · crmsa_heads=8
核心思想（"染色即区域" / Staining-as-Region）： 原 R²T 的 CR-MSA 把一张切片 K 个 region token 互相融合（S(R)）。本模型把它推广到染色维度——n 种染色各自 R²T 编码后，其 region token 被视为一张"虚拟超级切片"上的不同区域，用同一个 MSA 完成跨染色融合。 计算上无需真的拼出 2D 巨网格：纯注意力对排布方式（1D 拼接 / 2D 平铺 / 3D 堆叠）置换等变，直接在堆叠的 [B, nK, D] token 集合上做 MSA 即与巨网格布局逐位等价；每种染色独立过 R²T（Stage 1）即对应巨网格上的组内 R-MSA。
代码演进要点：
  • f342cce（官方对齐）：Stage 1 改用与官方 RRT-MIL 逐行一致的 RRTEncoder（TransLayer 封装的 CR-MSA，pre-LN+残差+DropPath）；HE/PR 编码器共享权重→独立权重；超参对齐官方 C16-PLIP 食谱（epeg_k=9, crmsa_k=3, crmsa_heads=8）
  • 本次（Stage 2 重写）：HE 锚定的 learned-query cross-attn（CrossRegionReembedding）→对称的跨染色 MSA（CrossStainingRegionMSA）：nK 个 region token 互相注意力；零初始化 fusion_gate；幻影区域 mask；旧版保留为 stage2_type='he_anchor' 消融对照
